# Лабораторная работа 4
## Тема: Ввод-вывод и работа с файлами в языке C
## Цель работы: освоить работу с файлами, открытие и закрытие потоков, чтение и запись текстовых и бинарных данных, форматированный ввод-вывод, перемещение по файлу.





## Ответы на вопросы:
1.	Файл в языке C — это последовательность байтов, с которой программа работает через поток.  
2.	Поток представляется указателем типа FILE*.Это указатель на структуру, которая хранит информацию об открытом файле. Его передают функциям для работы с файлом.
3.	Режимы открытия файлов
    "r" — чтение
    "w" — запись (перезаписывает файл)
    "a" — дозапись в конец файла
    "rb", "wb" — работа с бинарными файлами
 
4.	Текстовый хранит символы и читается человеком, бинарный хранит данные как в памяти и обычно меньше по размеру. 
5.	Посимвольный ввод-вывод:
    putc — запись символа
    getc — чтение символа
 
6.	Работа со строками:
    fputs — запись строки
    fgets — чтение строки
 
7.	Форматированный ввод-вывод:
    fprintf — запись в файл с форматированием
    fscanf — чтение из файла

8.	Для работы с бинарными данными используются функции:
    fwrite — запись блока данных
    fread — чтение блока данных
    Они позволяют записывать и читать массивы и структуры напрямую.
 
9.	Перемещение по файлу
    fseek — перемещает указатель в файле
    ftell — возвращает текущую позицию
    Пример:
    fseek(fp, 0, SEEK_END); — перейти в конец файла

10.	Проверка ошибок
    feof — проверяет конец файла
    ferror — проверяет ошибки при работе с файлом
 
11.	Чтобы сохранить данные на диск, освободить ресурсы системы и предотвратить утечки памяти.
