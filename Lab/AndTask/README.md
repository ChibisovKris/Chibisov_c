                      Итоговое задание
«Менеджер персональных данных с файлами и библиотеками C»


# Назначение программы

Программа предназначена для ведения списка персональных данных с возможностью сохранения и загрузки информации. Реализована на языке C с использованием динамической памяти и файлового ввода/вывода.

# Функциональные возможности

Программа обеспечивает выполнение следующих операций:

- Добавление новой записи с проверкой корректности вводимых данных
- Отображение всех сохранённых записей
- Сортировка записей по имени и по возрасту
- Расчёт статистических показателей (средний возраст, максимальный рост)
- Поиск записей по имени
- Поиск записей по диапазону возраста
- Сохранение данных в бинарный файл
- Загрузка данных из бинарного файла

# Структура данных

Для хранения информации о человеке используется структура, содержащая следующие поля:

- Имя (строковый тип)
- Возраст (целочисленный тип)
- Рост (тип с плавающей точкой)
- Год рождения (целочисленный тип)

# Управление памятью

Массив структур реализован динамически. Начальный размер выделяется при первом добавлении записи. При заполнении массива его вместимость увеличивается. Для управления памятью используются функции malloc, realloc и free.

# Проверка ввода

При добавлении записи выполняется проверка:

- Имя должно состоять только из буквенных символов
- Возраст должен быть положительным числом
- Рост должен быть положительным числом

При несоответствии условиям программа выводит сообщение об ошибке и не добавляет запись.

# Работа с файлами

Для сохранения и загрузки данных используется бинарный режим работы с файлами. При сохранении в файл сначала записывается количество записей, затем массив структур. При загрузке данные считываются в обратном порядке. Предусмотрена проверка успешности открытия файла.

# Организация меню

Управление программой осуществляется через консольное меню. Каждый пункт меню реализован в виде отдельной функции. Вызов функций выполняется через массив указателей на функции, что позволяет обойтись без условных операторов switch или множественных if.

# Используемые библиотеки

В программе задействованы следующие стандартные библиотеки C:

- stdio.h — для ввода/вывода и работы с файлами
- stdlib.h — для управления памятью
- string.h — для операций со строками
- ctype.h — для проверки символов

# Завершение работы

При выборе пункта выхода из программы выделенная динамическая память освобождается, после чего выполнение программы прекращается.
