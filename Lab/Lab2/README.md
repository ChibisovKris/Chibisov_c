Лабораторная работа 2
Структуры в языке C
Цель работы:
Изучить объявление и использование структур, вложенные структуры, указатели на структуры, массивы структур, передачу структур в функции, перечисления (enum) и объединения (union).

Ответы на вопросы:
1. struct имя_структуры
{
    компоненты_структуры
};

2. Вложенные структуры — это когда одна структура является полем другой, они нужны для логической группировки связанных данных и создания иерархических моделей.

3. Структуру можно передать в функцию по значению или по указателю (передается адрес, позволяет модифицировать оригинал и экономит память); при передаче по указателю для доступа к полям используется оператор `->`.

4. Массивы структур создавать можно, они объявляются аналогично массивам базовых типов с указанием размера или с инициализацией. Пример:
struct person people[10];

5. Доступ к элементу массива структур осуществляется через индекс с последующим обращением к полю через точку, либо через указатель со стрелкой. Пример: `arr[0].x = 5; (arr+1)->y = 10;`

6. Использовать `enum` внутри структуры можно, при этом enum определяет тип поля, которое хранит одно из перечисленных значений. Пример: 
`struct Item {
    char name[20];
    ItemType type;}`

7. Сравнивать структуры оператором `==` нельзя, так как компилятор не поддерживает побитовое сравнение составных типов напрямую; необходимо сравнивать поля по отдельности или использовать `memcmp` с учетом выравнивания (padding). Пример: `if (p1.x == p2.x && p1.y == p2.y) 
{ /* равны */ }`
