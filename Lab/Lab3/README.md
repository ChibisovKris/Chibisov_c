 Лабораторная работа 3
Динамические массивы в языке C
Цель работы: изучить работу с динамической памятью: функции malloc, calloc, realloc, free, создание и использование динамических массивов.

Ответы на вопросы:
1. Функция malloc - выделяет заданное количество байт памяти.
2. Различие между malloc и calloc
malloc:
•	не инициализирует память 
•	принимает один аргумент 
calloc:
•	заполняет память нулями 
•	принимает два аргумента 
3. Функция realloc - изменяет размер ранее выделенного блока памяти.
4. Память остается занятой до завершения программы.
5. Функция free - освобождает ранее выделенную память.
После вызова free память становится доступной для повторного использования.
6. Возникнет ошибка.
7. if (arr == NULL) {
ошибка обработки памяти
}
8. Отличие статических и динамических массивов
Статические массивы:
•	имеют фиксированный размер 
•	создаются при запуске программы 
•	автоматически освобождаются 
Динамические массивы:
•	размер задается во время выполнения 
•	требуют ручного управления памятью 
•	могут изменять размер
